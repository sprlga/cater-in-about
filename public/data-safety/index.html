Data Safety

Diperbarui 8 November 2026 · Versi aplikasi 1.0 Updated November 8, 2026 · App version 1.0

Tidak ada data yang dikumpulkan. Tidak ada data yang dibagikan.No data collected. No data shared. Catet.in tidak meminta akses internet maupun izin apa pun, sehingga tidak ada cara bagi aplikasi untuk mengirim data keluar dari perangkatmu. Catet.in requests neither internet access nor any permission, so the app has no way to send data off your device.
